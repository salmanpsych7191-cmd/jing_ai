Restaurant Retail AI Agent

A lightweight FastAPI dashboard for managing WhatsApp reservations, loyalty, and review campaigns.

What it does

  • Accepts bookings through WhatsApp or dashboard
  • Sends reservation reminders and review requests
  • Tracks loyalty points and voucher issuance
  • Provides a dashboard for live restaurant operations

Built with

FastAPI, Twilio WhatsApp, OpenAI/Groq, Deepgram transcription, SQLite, and APScheduler.
